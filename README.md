# استغفار

تطبيق أندرويد: شخصية تحمل وعاء "ذنوب"، وكل استغفارة تُسقط خرزة فيخفّ الحمل حتى ١٠٠ ثم يبدأ من جديد.

## أوضاع العدّ (من أيقونة الإعدادات أعلى اليسار)
- **تلقائي**: يعدّ وحده ثم يعيد من جديد.
- **تلقائي مع إيقاف مؤقت**: زر لإيقاف العدّ واستئنافه.
- **باللمس**: كل لمسة = استغفارة.
- مفتاح **الصوت**: صوت خفيف عند كل خرزة.

## الحصول على ملف APK
1. ارفع المشروع إلى GitHub (فرع `main`).
2. يعمل تلقائيًا workflow **Build APK** (تبويب Actions).
3. بعد دقائق تجد الملف `Istighfar.apk` في **Releases** أو داخل artifacts.

## الخطوط
الخطوط مضمّنة في `app/src/main/assets/fonts/`: خط **Nabi** للعبارات الكبيرة والآية، و**Rubik** (Light/Regular/Medium) لباقي النصوص.

## صفحة الترحّم
من الإعدادات: «ترحّم ومشاركة التطبيق». رابط المشاركة معرَّف بالمتغير `APP_LINK` في `index.html`.

## التذكير بالاستغفار (إشعارات)
من الإعدادات: مفتاح «التذكير بالاستغفار». يرسل إشعارًا يوميًا في ٦ ص، ١٠ ص، ٢ م، ٦ م، ١٠ م، ويعمل والهاتف مقفول.
- الأوقات والنصوص في `app/src/main/java/com/istighfar/app/Reminders.java` (`HOURS` و`MESSAGES`).
- يعيد جدولة نفسه بعد إعادة تشغيل الهاتف.

## الإصدار 1.3: تطبيق ديني متكامل
- **الشاشة الرئيسية** (`home.html`): المصحف، مواقيت الصلاة، عدّاد الاستغفار، الترحّم والإعدادات. زر الرجوع يعيد للرئيسية.
- **المصحف الشريف** (`quran.html`): المصحف المدني ٦٠٤ صفحات بخطوط مجمّع الملك فهد (QCF4، خط عثمان طه). فهرس السور والأجزاء، انتقال لصفحة، علامات مرجعية ★، وحفظ آخر صفحة تلقائيًا. السحب لليمين = الصفحة التالية.
  - النص والخطوط **لا تُكتب يدويًا**: تُجلب أثناء البناء في GitHub Actions من الحزمة `quran-qcf4@1.1.0` بواسطة `tools/prepare_quran.py` الذي **يوقف البناء** إن نقص شيء (٦٠٤ صفحة، ١١٤ سورة، ٦٢٣٦ آية، كل الخطوط). لا يعدّل أي حرف.
- **مواقيت الصلاة** (`prayer.html`): تُحسب داخل الجهاز دون إنترنت حسب الموقع. طرق الحساب: رابطة العالم الإسلامي، المصرية، كراتشي، أم القرى، ISNA، الجعفري (طهران/ليفا). العصر جمهور/حنفي. اتجاه القبلة. تنبيه الأذان بصوت الإشعار العادي لكل صلاة (جرس 🔔).
  - عند أول دخول يُطلب تفعيل الموقع، ويُعرض اسم المحافظة/الدولة إن توفّر.
  - تنبيهات الصلاة تُجدول لـ ٧ أيام عند كل فتح للتطبيق (وبعد إعادة تشغيل الهاتف). افتح التطبيق مرة في الأسبوع على الأقل.
- حقوق الخطوط: مجمّع الملك فهد لطباعة المصحف الشريف.

## التحديث الداخلي (1.4)
- عند فتح الشاشة الرئيسية يسأل التطبيق GitHub عن آخر إصدار؛ إن وُجد أحدث يظهر «تحديث جديد» مع زر «تحديث الآن» (ينزّل `Istighfar.apk` ويفتح مثبّت النظام). وفي الرئيسية زر «التحقق من وجود تحديث».
- أول مرة يطلب النظام السماح للتطبيق بـ«تثبيت التطبيقات المجهولة».
- كل رفع جديد = إصدار أحدث تلقائيًا (`versionCode = 100 + رقم تشغيل Actions`). غيّر `versionName` في `app/build.gradle` لتظهر الأرقام الجديدة، وعدّل `RELEASE_NOTES.md` لنص التحديث.
- التوقيع ثابت بالملف `app/istighfar.keystore` (ضروري كي يقبل أندرويد التحديث فوق النسخة القديمة). لا تحذفه. **أول مرة فقط** يجب حذف النسخة المثبتة القديمة (الموقّعة بمفتاح مختلف) ثم تثبيت 1.4 يدويًا.
