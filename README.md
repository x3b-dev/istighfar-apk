# استغفار

تطبيق أندرويد: شخصية تحمل وعاء "ذنوب"، وكل استغفارة تُسقط خرزة فيخفّ الحمل حتى ١٠٠ ثم يبدأ من جديد.

## أوضاع العدّ (من أيقونة الإعدادات أعلى اليسار)
- **تلقائي**: يعدّ وحده ثم يعيد من جديد.
- **تلقائي مع إيقاف مؤقت**: زر لإيقاف العدّ واستئنافه.
- **باللمس**: كل لمسة = استغفارة.
- مفتاح **الصوت**: صوت خفيف عند كل خرزة.

## الحصول على ملف APK
1. ارفع المشروع إلى GitHub (فرع `main`).
2. يعمل تلقائيًا workflow **Build APK** (تبويب Actions).
3. بعد دقائق تجد الملف `Istighfar.apk` في **Releases** أو داخل artifacts.

## الخطوط
الخطوط مضمّنة في `app/src/main/assets/fonts/`: خط **Nabi** للعبارات الكبيرة والآية، و**Rubik** (Light/Regular/Medium) لباقي النصوص.

## صفحة الترحّم
من الإعدادات: «ترحّم ومشاركة التطبيق». رابط المشاركة معرَّف بالمتغير `APP_LINK` في `index.html`.

## التذكير بالاستغفار (إشعارات)
من الإعدادات: مفتاح «التذكير بالاستغفار». يرسل إشعارًا يوميًا في ٦ ص، ١٠ ص، ٢ م، ٦ م، ١٠ م، ويعمل والهاتف مقفول.
- الأوقات والنصوص في `app/src/main/java/com/istighfar/app/Reminders.java` (`HOURS` و`MESSAGES`).
- يعيد جدولة نفسه بعد إعادة تشغيل الهاتف.


## التحديث داخل التطبيق (2.2)
- من الإعدادات: «التحديث»، أو يفحص تلقائيًا بعد ثوانٍ من فتح التطبيق ويعرض نافذة التحديث عند وجود إصدار أحدث.
- النافذة بنفس تصميم التطبيق (خط Nabi وRubik، أخضر وذهبي)، مع «ما الجديد» من ملف `RELEASE_NOTES.md` وشريط تقدّم.
- يقرأ آخر إصدار من GitHub Releases (`Updater.java`) ويحمّل `Istighfar.apk` ويسلّمه لمثبّت النظام.
- مفتاح التوقيع `app/istighfar.keystore` ثابت: لا تحذفه حتى تُثبَّت التحديثات فوق النسخة القديمة.
