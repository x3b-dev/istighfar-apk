# استغفار

تطبيق أندرويد (WebView): شخصية تحمل وعاء «ذنوب»، وكل استغفارة تُسقط خرزة فيخفّ الحمل حتى ١٠٠ ثم يبدأ من جديد.

## الشاشات
- `istighfar.html`: المشهد الرئيسي (يفتح عليه التطبيق)، شعار متحرك عند التشغيل، ترحيب أول مرة، «ما الجديد»، نافذة التحديث، الترحّم والمشاركة. الترس الصغير يفتح: التسبيح، القبلة، المظهر، اللغة، الإشعارات، أوضاع العدّ.
- `qibla.html`: بوصلة القبلة ووضع الكاميرا (يطلب الموقع والكاميرا عند فتحه فقط).
- `tasbih.html`: المسبحة.
- الرجوع: من التسبيح/القبلة يعود للاستغفار، ومن الاستغفار يخرج التطبيق.

## الملفات
`common.js` أدوات عامة، `core.js` اللغات والمظهر والأيقونات، `i18n2.js` نصوص إضافية، `extra.js/css` الشعار المتحرك والترحيب والتحديث، `motion.css` نظام الحركة.
